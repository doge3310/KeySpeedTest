## Tuping speed test
Консольное приложение для проверки скорости печати (без вывода скорости печати)).
Для работы просто запусти приложение, как только закончишь писать предложение и захочешь начать писать новое нажми ENTER.
Для выхода нажми ESC.
В data.txt можешь запихать любой английский текст.
